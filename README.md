## 👤 Sobre este proyecto

Portafolio / presentación de ventas personal con diseño **cyberpunk neón** — colores cyan, verde radioactivo, violeta y rosa. Creado para compartir en WhatsApp, redes sociales o como link profesional.

## ✨ Características

- ⚡ Efecto GLITCH animado en el nombre
- 🌐 Partículas neón flotantes (cyan / verde / violeta / rosa)
- 📺 Scanlines estilo CRT
- 🖱️ Rastro de luz al mover el cursor
- 📊 Barra de progreso arcoíris al hacer scroll
- 🪟 **4 ventanas flotantes arrastrables** (Contacto, Status, Skills, Logros)
- 🖥️ Taskbar inferior con reloj en tiempo real
- 📱 Responsive — funciona en móvil y desktop
- 🔗 Botón de llamada directa al teléfono

## 🚀 Cómo publicar (GitHub Pages)

1. Ve a tu repo → **Settings** → **Pages**
2. En *Source* selecciona **Deploy from a branch**
3. Rama: `main` / Carpeta: `/ (root)`
4. Clic en **Save**
5. En ~2 minutos tu sitio estará en:
   `https://demitry001-sketch.github.io/Adrian-B`
